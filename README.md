# 동방속기 연습장

동방속기 기초 문자를 직접 써 보며 익히는 연습용 웹 앱입니다. 빌드 없이 `index.html`을 브라우저로 열면 동작합니다.

## 기능
- 개념(지식 요소) 단위의 맞춤 학습: 배운 개념만으로 풀 수 있는 문제가 열립니다.
- 새 개념마다 설명 카드, 대시보드에서 지난 개념 다시 보기
- 문자 모양 ↔ 글자, 단어 이어쓰기 모양 고르기, 모음 길이(1:2:4 비율) 문제
- 연속 학습 일수, 경험치(XP), 하트 같은 일반적인 학습 진행 표시

## 구성
| 파일 | 내용 |
| --- | --- |
| `index.html` | 진입 페이지 |
| `src/styles.css` | 스타일(자체 색상 토큰, 다크 모드 지원) |
| `src/dongbang-engine.js` | 속기 문자·단어를 SVG로 그리는 엔진 |
| `src/words.js` | 연습 단어 목록 |
| `src/concepts.js` | 규칙 개념 요약 |
| `src/app.js` | 학습 진행·문제 생성·화면 |

## 저작권 안내
이 저장소에는 교재의 본문이나 원본 이미지가 들어 있지 않습니다. 문자 모양은 규칙(방향·길이·곡선)에서 직접 계산해 그리며, 설명은 직접 요약한 것입니다. 이 앱은 비공식 연습 도구이며 교재 저자·출판사와 무관합니다. 정확한 내용은 교재를 확인하세요.

## 개발: 영역별 병렬 작업
새 학습 영역은 `src/features/<이름>.js` 한 파일에서 `FEATURES`에 객체를 등록해 추가합니다(개념 id 접두어, 설명 카드, 문제 종류, 단어, 대시보드 구역). 등록 형식은 `src/app.js`의 "기능 확장 등록" 주석에 있습니다. 영역별 파일이 달라 서로 충돌하지 않습니다. 기본 영역은 `batchim.js`(받침), `ae-vowel.js`(ㅐ모음), `abbreviations.js`(약기법)가 비어 있습니다. 공용 엔진(`dongbang-engine.js`)은 가능하면 수정하지 말고 영역 파일에 함수를 추가하세요.

`artifact.html`은 아티팩트 게시용 진입 파일이고, `index.html`과 스크립트 목록이 같습니다.

### 단어를 추가할 때
교재에 이어쓰기 그림이 있는 단어만 `WORDS`에 넣고, 그 밖의 일반 단어는 `DICT`(또는 영역 파일의 목록)에 넣되 `drawsClean(word)`로 선이 겹치지 않는지 검사해 통과한 것만 문제에 쓰세요. 반소원(ㅑ모음) 글자가 앞 선과 이어질 때 생기는 잎사귀 모양이 대표적인 탈락 사유입니다.

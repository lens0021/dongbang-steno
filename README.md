# 동방속기 연습장

동방속기 기초 문자를 직접 써 보며 익히는 연습용 웹 앱입니다. 빌드 없이 `index.html`을 브라우저로 열면 동작합니다.

## 기능
- 개념(지식 요소) 단위의 맞춤 학습: 배운 개념만으로 풀 수 있는 문제가 열립니다.
- 새 개념마다 설명 카드, 대시보드에서 지난 개념 다시 보기
- 문자 모양 ↔ 글자, 단어 이어쓰기 모양 고르기, 모음 길이(1:2:4 비율) 문제
- 연속 학습 일수, 경험치(XP), 하트 같은 일반적인 학습 진행 표시

## 구성
| 파일 | 내용 |
| --- | --- |
| `index.html` | 진입 페이지 |
| `src/styles.css` | 스타일(자체 색상 토큰, 다크 모드 지원) |
| `src/dongbang-engine.js` | 속기 문자·단어를 SVG로 그리는 엔진 |
| `src/words.js` | 연습 단어 목록 |
| `src/concepts.js` | 규칙 개념 요약 |
| `src/app.js` | 학습 진행·문제 생성·화면 |

## 저작권 안내
이 저장소에는 교재의 본문이나 원본 이미지가 들어 있지 않습니다. 문자 모양은 규칙(방향·길이·곡선)에서 직접 계산해 그리며, 설명은 직접 요약한 것입니다. 이 앱은 비공식 연습 도구이며 교재 저자·출판사와 무관합니다. 정확한 내용은 교재를 확인하세요.
